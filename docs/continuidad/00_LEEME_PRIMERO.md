## Proyectos separados
ANUBIS MAG tiene tres proyectos relacionados, pero no deben mezclarse sin autorización:
- **ANUBIS MAG TACTICAL**: aplicación táctica principal de este repositorio.
- **RESPAWN ANUBIS MAG**: aplicación independiente de respawn.
- **ANUBIS MAG MISSIONS**: aplicación independiente para misiones.

Este kit documenta el contexto conocido hasta el 22 de noviembre de 2026. Los estados descritos deben verificarse contra GitHub, la aplicación publicada y Supabase antes de actuar; no asumir que un despliegue está terminado solo porque se inició.

## Importante
No guardar contraseñas, claves privadas, tokens, claves secretas de Supabase ni códigos de autenticación en estos documentos. El ID de proyecto de Supabase no es una clave secreta, pero no debe confundirse con credenciales.
